## 🎯 Highlighted Projects

Here are the projects that highlight my engineering and problem-solving capabilities.

### 1. Large Vehicle Maintenance via AR/VR & IoT (Hackathon Winner)
*An immersive diagnostics platform built to modernize heavy machinery repair workflows.*
* **The Stack:** Unity 6, Blender, C#, Node.js, TypeScript, Arduino Uno (Sensors: ACS712), Firebase.
* **Key Implementations:**
  * **Digital Twin Mechanics:** Immersive, interactive 3D models for Virtual Reality environments to simulate heavy layouts safely.
  * **IoT Telemetry:** Embedded Arduino hardware to harvest live situational data, streaming instantly to Firebase.
  * **AR Overlays:** Displays high-resolution, skeletal wiring system blueprints directly over the machinery to visually guide field technicians.

### 2. Dual-Engine Hospital Management System
*A comprehensive data tracking suite optimized across different database paradigms to scale medical operations data.*

<details>
<summary><b>🔹 Variant A: Relational Engine (MySQL)</b></summary>

* **The Stack:** Python (Tkinter, `python-mysql`), MySQL Editor.
* **Architecture Highlights:** Deep data architecture using custom-built tables to support high-integrity relationship queries.
* **Modules:** Ambulance dispatch routing, localized request handling, conditional medical reporting, and dynamic chronological appointment tracking.
* 🖥️ **Repository:** [View Source Code](https://github.com/udhaypvr/hospital-management-system-mysql)
</details>

<details>
<summary><b>🔹 Variant B: Non-Relational Engine (MongoDB)</b></summary>

* **The Stack:** Python (Tkinter), MongoDB Cloud Server.
* **Architecture Highlights:** Unstructured, highly scalable BSON data document handling optimized for fast lookup.
* **Modules:** Mirroring the functional modules of the MySQL instance but operating on flexible document clusters.
* 🖥️ **Repository:** [View Source Code](https://github.com/udhaypvr/hospital-management-system-mongodb)
</details>
